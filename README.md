## 📌 Overview
Welcome to the **Operating Systems Lab** repository. This repository contains the source code, assignments, and practical implementations of various core Operating System concepts. The labs are designed to provide hands-on experience with system calls, process management, memory management, and concurrency.

## 🛠️ Prerequisites
Before running the code in this repository, ensure you have the following installed:
*   A Linux/Unix environment (Ubuntu, Debian, macOS, or WSL for Windows).
*   **GCC Compiler** (GNU Compiler Collection).
*   **Make** (Build automation tool).
*   Basic knowledge of the C programming language.
